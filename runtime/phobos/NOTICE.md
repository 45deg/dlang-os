# Upstream Phobos provenance

The source is ldc-developers/phobos commit
`4d4842eff1f50b9edd90b9a7fc470a7b2fc4e85c`, the submodule revision pinned by
LDC v1.43.0 (LDC commit `ad42ba07be491c79a16a04e17ce54c06d8943c03`).
The archive URL and SHA-256 are in source.lock.json.

LICENSE_1_0.txt is the unmodified upstream Boost Software License 1.0.
The complete upstream archive retains every file's copyright and license notices.
Builds apply the tracked patches to separate copies. The original source and
notices remain unchanged. This does not relicense the surrounding OS project.

The output subset compiles std.stdio, std.utf and std.exception, their imported
templates, and additional druntime modules. The implementation of writeln and
File.LockingTextWriter remains upstream code. The stdio patch selects the
DlangOS C ABI, single-thread stream locks and explicit unsupported file operations.
The druntime patch supplies page size and omits floating-point TypeInfo definitions
because the OS does not yet preserve floating-point/SIMD registers.

See ../druntime/NOTICE.md and its original license files for druntime provenance.
The OS adapters use a process-lifetime allocator with no tracing collection.
No host libc, Phobos binary or compiler runtime is linked.

Redistribute these notices, license texts, source locks, original source archives,
patches and platform adapter sources with the development bundle generated by
make phobos-package. The build report records source revisions and commands.
