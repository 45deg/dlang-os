# デスクトップアプリの登録

DlangFSに `desktop.apps` を配置すると、次回起動時からランチャーの登録を置き換えます。カーネルの再ビルドは不要です。設定がない場合は同梱6アプリの既定設定を使います。ELF自体は別途ディスクに配置してください。設定ファイルもDlangFSのファイル枠を1つ使います。

例として、別のELF `example.elf` とEditorを登録します。

```text
DLANGAPPS1
Example|example.elf|generic|80|60|300|180|1|F8|-
Writer|editor.elf|editor|220|90|468|340|4|F9|document
```

各行は `|` で区切った次の10項目です。空白の自動除去や引用符によるエスケープは行いません。

| 項目 | 内容 |
| --- | --- |
| 表示名 | 印字可能ASCII、1〜24文字 |
| ELF名 | DlangFSのファイル名、1〜24文字。重複不可 |
| アイコン | `files`、`editor`、`counter`、`calc`、`game`、`monitor`、`generic` |
| x | -2048〜2048。負数は画面右端からの位置 |
| y | 0〜2048 |
| 幅 | 128〜768ピクセル。窓枠を含む |
| 高さ | 80〜520ピクセル。窓枠を含む |
| 同時起動数 | 0〜7。0は全体の窓上限まで、1は既存の窓を前面に戻す |
| 起動キー | `-`、`F5`、`F8`、`F9`。キーの重複不可 |
| 文書担当 | `-` または `document`。文書担当は最大1アプリ |

アイコンは見た目だけを指定します。文書担当はFilesからの文書を開く要求やF2の新規文書を受け取るため、対象ELFがGUIの文書イベントに対応している必要があります。担当がなければ文書を開く操作はエラー表示になります。

配置は登録順で、窓は重なる場合に右へ24、下へ29ピクセルずらします。画面端では位置を調整します。登録は1〜12件、設定全体は4096バイトまでです。LFとCRLF、空行、行頭 `#` のコメント、最終改行なしに対応します。先頭の有効行は `DLANGAPPS1` が必要です。

保存にはシリアルシェルの `put desktop.apps バイト数` を使うか、ホストの `tools/install-apps.py --app /path/to/desktop.apps` を使います。インストーラは既存ファイルを上書きしません。更新には `put` を使ってください。

設定は起動時に専用メモリへコピーします。起動後の編集や削除は次回起動で反映します。不正な形式、上限超過、重複した登録は全体を拒否して既定設定へ戻り、画面にエラーを表示します。部分適用や設定ファイルへの書き戻しは行いません。シリアルシェルから修正・削除して再起動できます。

ランチャーに登録しないGUIアプリも `run NAME &` と `guiCreate` で窓を作れます。この場合は共通の既定サイズを使います。
