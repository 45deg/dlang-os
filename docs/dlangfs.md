# DlangFSのディスク形式

整数はすべてリトルエンディアン、セクタは512バイトです。ファイルごとに2世代を保持し、本文を書き込んでからメタデータを確定します。カーネル内のバッファ上限は `file_api.d`、ディスク上の配置は以下の形式で定義しています。上限を変更しても、既存ディスクの配置は変わりません。

## DlangFS

LBA 0には次のヘッダを保存します。マウントや通常の保存ではこの領域を変更しません。

| オフセット | サイズ | 内容 |
| --- | --- | --- |
| 0 | 8 | `DLANGFS1` |
| 8 | 4 | 形式バージョン：1 |
| 12 | 4 | セクタサイズ：512 |
| 16 | 4 | ファイルスロット数 |
| 20 | 4 | 1ファイルの最大バイト数 |
| 24 | 4 | データ開始LBA |
| 28 | 4 | 1世代のセクタ数（メタデータを含む） |
| 32 | 4 | メタデータサイズ：36 |
| 36 | 4 | ファイル名領域のバイト数：24 |
| 40 | 4 | ヘッダチェックサム |
| 44 | 468 | 予約領域：0 |

チェックサムは、オフセット40〜43を除いたヘッダ全体に対するFNV-1a 32bitです。初期値を `2166136261` とし、各バイトでXORを取った後に `16777619` を掛けて32bitに切り詰めます。

スロット番号を `slot`、世代の位置を `copy`（0または1）とすると、メタデータのLBAは `recordsLba + (slot * 2 + copy) * sectorsPerCopy` になります。本文はその次のセクタから始まります。世代間の間隔は `1 + ceil(fileBytes / 512)` 以上必要です。余分なセクタやデータ開始位置より前の領域には書き込みません。

スロット数と最大サイズは正の値、データ開始LBAは1以上とします。実装のバッファ上限（1 MiB）、形式ごとの本文長、ドライバのアドレス範囲、またはディスク末尾を超える配置は拒否します。ヘッダのバージョン、各サイズ値、予約領域、チェックサムのいずれかが不正な場合も、書き込みを行わずマウントを拒否します。ヘッダの自動復旧機能はありません。

各世代のメタデータは、先頭から順に世代番号（uint32）、チェックサム（uint32）、本文長（uint32）、名前（24バイト、余りは0）で構成されます。チェックサムは、自身の4バイトを除いたメタデータと使用済み本文を連結したデータに対するFNV-1aです。名前が空の有効な世代は削除を表します。全ゼロのメタデータセクタは未使用です。

`tools/format-disk.py` は標準でDlangFS、16スロット、1ファイル1 MiBの新規イメージを作成します。既定のイメージサイズはレイアウトに必要な33,571,328バイトです。`--size-bytes` を指定した場合、容量不足やセクタ境界違反は拒否します。既存のファイルは上書きせず、既存ディスクの容量変更や再配置も行いません。
