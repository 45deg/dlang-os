# DlangFSのディスク形式

すべての整数はリトルエンディアン、セクタは512バイトです。ファイルごとに2世代を保持し、本文を書いてからメタデータを確定します。カーネル内のバッファ上限は `file_api.d`、ディスク上の配置は以下の形式で定義します。上限の変更は既存ディスクの配置を変更しません。

## DlangFS3

LBA 0には次のヘッダを保存します。マウントや通常の保存では変更しません。

| オフセット | サイズ | 内容 |
| --- | --- | --- |
| 0 | 8 | `DLANGFS3` |
| 8 | 4 | 形式バージョン：3 |
| 12 | 4 | セクタサイズ：512 |
| 16 | 4 | ファイルスロット数 |
| 20 | 4 | 1ファイルの最大バイト数 |
| 24 | 4 | データ開始LBA |
| 28 | 4 | 1世代のセクタ数（メタデータを含む） |
| 32 | 4 | メタデータサイズ：34 |
| 36 | 4 | ファイル名領域のバイト数：24 |
| 40 | 4 | ヘッダチェックサム |
| 44 | 468 | 予約領域：0 |

チェックサムはオフセット40〜43を除いたヘッダ全体のFNV-1a 32bitです。初期値2166136261、各バイトでXORした後に16777619を掛け、32bitに切り詰めます。

スロット番号を `slot`、世代の位置を `copy`（0または1）とすると、メタデータのLBAは `recordsLba + (slot * 2 + copy) * sectorsPerCopy` です。本文はその次のセクタから始まります。間隔は `1 + ceil(fileBytes / 512)` 以上必要です。余分なセクタとデータ開始位置より前の領域には書き込みません。

スロット数と最大サイズは正数、データ開始LBAは1以上とします。実装のバッファ上限、16bitの本文長、ドライバのアドレス範囲、ディスク末尾を超える配置は拒否します。ヘッダのバージョン・寸法・予約領域・チェックサムが不正な場合も、書き込みを行わずマウントを拒否します。ヘッダの自動復旧はありません。

各世代のメタデータは、順に世代番号（uint32）、チェックサム（uint32）、本文長（uint16）、名前（24バイト、余りは0）です。チェックサムは自身の4バイトを除いたメタデータと、使用済み本文の連結に対するFNV-1aです。名前が空の有効な世代は削除を表します。全ゼロのメタデータセクタは未使用です。

`tools/format-disk.py` はこのヘッダを持つ新規イメージを作成します。既存のファイルは上書きしません。既存ディスクの容量変更や再配置は行いません。

DlangFS3のみ対応しています。DlangFS1/2はマウントせず、読み書きや自動移行を行いません。
